## Installation

Use Python 3.9 or newer. Install the required packages:

```bash
python -m pip install numpy pandas scipy matplotlib seaborn upsetplot matplotlib-venn
```

## Run

From the directory containing the scripts and input files, run:

```bash
python MelanomaBrainMutations_.py
python MelanomaBrainMutations_Data_Figures.py
```

If plot windows open, close them to allow execution to continue.

## Outputs

Statistical tables are saved in `stats_out/`. Figures and OncoPrint input files are saved in `stats_out/`, `plots/`, or the working directory, as specified in the scripts.
